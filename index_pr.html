Coleta de Dados e Desenvolvimento de Ferramentas

Desenvolvimento de ferramentas para coletar, pré-processar e gerenciar dados ambientais e espaciais, promovendo fluxos de trabalho reprodutíveis e monitoramento eficiente.

  • Aplicativos GEE: Interfaces para selecionar e exportar dados de satélite por período, área de interesse e cobertura de nuvens.
  • Scripts Python/R: Automatização da coleta, limpeza e transformação de dados satelitais e tabulares.
  • Apps em R Shiny: Ferramentas interativas para monitoramento da terra e análise de NDVI.

Design e Gestão de Bancos de Dados

Projeto e manutenção de bancos de dados geoespaciais para projetos de monitoramento de carbono e uso da terra em diversos países.

  • PostgreSQL/PostGIS: Desenvolvimento de geobancos escaláveis para projetos REDD e ARR com polígonos e atributos.
  • Integração com GeoNode: Plataformas colaborativas para compartilhamento de dados geoespaciais.
  • SQL + R: Consultas SQL para geração de relatórios automatizados e análises espaciais.
