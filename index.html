Remote Sensing

Sentinel-2 Image Processing App: GEE based app for image processing in the framework of the projects PINV01-528 and PINV01-530 funded by the National Council of Science and Technology (CONACYT-Paraguay). It is intended to produce spatio-temporal images corresponding to pixel based statistics (temporal dimension), such as the mean, range, median, std between others, given a set of parameters (Boundaries, time period, type of time aggregation, spatial filters, etc.). These images are use as time-series data for ecological nich models (ENMs) in order to model habitat suitability for a set of different species which range from desease vectors to wildlife in natural reserves.

Land cover monitoring App: This tool is intended for combining the different sources of satellite imagery, process them and produce insightful statistics over a given area, following a logic of reference vs current period.
