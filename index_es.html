Recolección de Datos y Desarrollo de Herramientas

Desarrollo herramientas para recolectar, preprocesar y manejar datos ambientales y espaciales, fomentando flujos de trabajo reproducibles y monitoreo eficiente.

  • Apps en GEE: Interfaces para seleccionar y exportar imágenes satelitales por tiempo, AOI y nubosidad.
  • Scripts en Python/R: Automatización de descarga, limpieza y transformación de datos satelitales y tabulares.
  • Apps en R Shiny: Herramientas interactivas para monitoreo territorial y análisis de NDVI.

Diseño y Gestión de Bases de Datos

Diseño y mantengo bases de datos geoespaciales para proyectos de monitoreo de carbono y uso del suelo en varios países.

  • PostgreSQL/PostGIS: Geobases escalables para proyectos REDD y ARR.
  • Integración con GeoNode: Plataformas colaborativas para compartir datos espaciales.
  • SQL + R: Consultas SQL para informes automatizados y análisis espacial.
